# **ここに書いていない銘柄は永久に見つからない。** Yahooには「全米国株を
# 売買代金順に並べる」入口が無いため、順位はこのリストの中だけで付く。
# 取引所全体から発見したい場合はIBKRのスキャナー購読が要る。
#
# 1行1銘柄。空行と # で始まる行は無視される。
#
# 2026-08-05に63銘柄から現在の規模へ拡大した。63銘柄では --top 100 の
# 足切りに誰も掛からず、全銘柄が毎日ランク内に居た。つまり
# AttentionConfig.absent_rank（ランク外＝101位扱い）が一度も効かず、
# 「ランク外から上位へ入ってきた」という急上昇の主要な形を観測できない。
# 順位が意味を持つには、ユニバースが上位100より十分に大きい必要がある。
#
# **全銘柄がyfinanceで実際に取得できることを確認して並べてある**
# （2026-08-05時点）。買収・ティッカー変更で無効になった銘柄を残すと、
# 取得率が MIN_FETCH_RATIO(0.8) を割ってその日の記録ごと見送られる。
# 実際にこの日、旧リストにあった SQ(->XYZ)・PARA・K・HES・DFS などが
# 空を返した。**定期的に取得失敗を確認して手入れすること。**
#
